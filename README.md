# CSLA Starter

A secure, bilingual starter template for Government of Canada line-of-business web applications, built on .NET 10, Blazor Server and CSLA 10.2. New applications start with Entra ID sign-in, property- and record-level permissions, a full audit trail with change history, live updates between users, and English and French throughout, on a Protected B security baseline.

**Status:** foundation in progress.
