# CSLA Starter

A starter template for Government of Canada line-of-business web applications, built on .NET 10, Blazor Server, CSLA 10.2 and EF Core with PostgreSQL. Apps are made from it with `dotnet new csla-blazor`.

**Status:** the starter is being rebuilt, one slice at a time. Today it has its three projects (`CslaStarter.Domain`, `CslaStarter.Data` and `CslaStarter.Web`), the vendored GC Design System, and the architecture tests that keep the project boundaries. Features arrive with the next slices.
